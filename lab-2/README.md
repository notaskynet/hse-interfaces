## Шаг 2. Разобраться с обменом MCP3204

АЦП 12-битный, опора 4,096 В, то есть 1 единица кода = 1 мВ: `U = code × 4,096 / 4096`.

Режим SPI — 0,0 (или 1,1), старший бит первым. Частота SCK — не выше 1 МГц с запасом (предел 2 МГц при 5 В) и не ниже ~10 кГц, иначе разряжается конденсатор выборки.

Настройка и чтение результата идут одной посылкой из трёх байт при `CS = 0` (диаграмма на стр. 14):

| Байт | Передаём                          | Принимаем                          |
|------|-----------------------------------|------------------------------------|
| 1    | `0000 0 1 SGL D2` — старт-бит, SGL/DIFF, D2 | мусор                     |
| 2    | `D1 D0 xx xxxx`                   | `? ? ? 0 B11 B10 B9 B8`            |
| 3    | любой                             | `B7 … B0`                          |

Для несимметричного входа SGL/DIFF = 1, D2 не важен, D1:D0 — номер канала (таблица на стр. 13). Для CH0 передаём `0x06, 0x00, 0x00`.

- [ ] Результат: `code = ((rx2 & 0x0F) << 8) | rx3`.
- [ ] Между измерениями обязательно поднимать CS — по нему АЦП сбрасывает счётчик бит.

## Шаг 3. Прошивка: SPI и АЦП

- [ ] Настроить выводы:
  - RC5 (SDO) и RC3 (SCK) — выходы (`TRISC<5> = 0`, `TRISC<3> = 0`), RC4 (SDI) — вход;
  - вывод CS — выход, исходно 1;
  - если CS или что-то ещё на порту A — отключить аналоговые входы через `ADCON1`.
- [ ] Настроить MSSP в режим SPI Master, режим 0,0:
  - `SSPSTAT`: SMP = 0, CKE = 1;
  - `SSPCON1`: CKP = 0, SSPM = `0001` (Fosc/16; при 8 МГц это 500 кГц), SSPEN = 1 — итого `SSPCON1 = 0x21`.
- [ ] Обмен байтом: записать в `SSPBUF`, дождаться BF = 1 (`SSPSTAT<0>`), прочитать `SSPBUF`. Читать нужно всегда, даже если принятый байт не нужен.

```c
unsigned char spi_xfer(unsigned char b) {
    SSPBUF = b;
    while (!SSPSTAT.BF);
    return SSPBUF;
}

unsigned int adc_read(unsigned char ch) {   // ch = 0..3
    unsigned char hi, lo;
    ADC_CS = 0;
    spi_xfer(0x06);                 // старт-бит, SGL/DIFF = 1, D2 = 0
    hi = spi_xfer(ch << 6);         // D1, D0
    lo = spi_xfer(0x00);
    ADC_CS = 1;
    return ((unsigned int)(hi & 0x0F) << 8) | lo;
}
```

Если на плате ATmega128 (mikroC PRO for AVR), логика та же, меняются регистры:

- выводы: SS — PB0, SCK — PB1, MOSI — PB2, MISO — PB3; PB0 обязательно сделать выходом, иначе SPI может выпасть из режима Master;
- `SPCR = (1 << SPE) | (1 << MSTR) | (1 << SPR0)` — Master, режим 0, Fosc/16;
- обмен: записать в `SPDR`, ждать SPIF в `SPSR`, прочитать `SPDR`.

## Шаг 5. Приложение на Qt с графиком

- [ ] Взять за основу терминал из lab-1: выбор порта и скорости, открытие и закрытие, вывод ошибок.
- [ ] Подключить QCustomPlot:
  - скачать `qcustomplot.h` и `qcustomplot.cpp` с [qcustomplot.com](https://www.qcustomplot.com/) и добавить в проект;
  - в `.pro`: `QT += serialport printsupport`;
  - в Qt Designer положить `QWidget` и сделать Promote to → `QCustomPlot`.
- [ ] Приём: в слоте `readyRead` читать, пока `canReadLine()`. Данные приходят кусками, строку нельзя разбирать, пока она не пришла целиком. Мусорные строки пропускать (`toInt(&ok)`).
- [ ] График:
  - `addGraph()`, по оси X — время в секундах от открытия порта (`QElapsedTimer`), по оси Y — код 0–4095 или напряжение 0–4,1 В;
  - на каждый отсчёт `graph(0)->addData(t, value)`;
  - окно последних 10 секунд: `xAxis->setRange(t, 10, Qt::AlignRight)`;
  - старые точки удалять (`graph(0)->data()->removeBefore(t - 10)`), иначе память растёт;
  - `replot()` вызывать по таймеру раз в 30–50 мс, а не на каждый отсчёт.
- [ ] Полезно вывести рядом текущее значение: код в HEX и напряжение в вольтах.

Без платы приложение можно проверить на виртуальной паре портов:

```sh
socat -d -d pty,raw,echo=0 pty,raw,echo=0
while true; do echo $((RANDOM % 4096)); sleep 0.05; done > /dev/ttys00X
```

Виртуальных портов нет в списке — имя второго порта (`/dev/ttys00Y`) нужно ввести в поле «Порт» вручную или передать при запуске: `monitor --port /dev/ttys00Y --baud 19200`.
